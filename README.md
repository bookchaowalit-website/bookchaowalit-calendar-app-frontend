# Calendar App

Month view calendar with create/edit/delete events.

## Features
- Month navigation
- Click a day to add an event
- Events list for selected day
- Persist via localStorage

## Limitations
- Single-user local demo
- No recurrence / invitations / sync

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- localStorage persistence

## Run
```bash
npm install
npm run dev
```

## Honesty notes
- Portfolio mini-app showcase
- Not multi-tenant SaaS
